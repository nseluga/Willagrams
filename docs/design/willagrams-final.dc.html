Willagrams — polished screens

Six iPhone screens, built on the repo's own tokens: Instrument Sans and Fragment Mono, #1A1710→#14120C ground, #F0E7D0 ink, #D6C39A tile faces, #D9A03C accent, 5pt tile radii, 14pt panels. No functionality was added or removed — Play a Friend and Join a Friend are merged into one screen with a mode switch, and the loading screen is new. Rule copy is verbatim from Shell/HowToPlay.swift.

Every screen is live: type a code, toggle Host/Join, save a name, copy, look up a friend, page the rules, mute.
